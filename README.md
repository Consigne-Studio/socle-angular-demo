# Socle Angular : démonstration

Application de démonstration de **Socle**, starter Angular 22 de qualité industrielle : zoneless,
signals, 13 quality gates en une commande, CI GitHub, GitLab et Jenkins prêtes.

**Voir la démo :** https://consigne.github.io/socle-angular-demo/

Ce dépôt ne contient que le build de production de la démonstration. L'API est simulée dans le
navigateur et les données sont fictives : vos modifications disparaissent au rechargement.

Le code source complet, la documentation et les pipelines sont vendus sur la page du produit.
